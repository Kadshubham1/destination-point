# Destination Point Website

A modern, responsive single-page website for Destination Point focusing on two core services:
- **Digital Marketing**
- **Counselling and Guidance**

## Deploying to Render

This project is configured as a Static Site for [Render](https://render.com).

### Option 1: Via Render Dashboard
1. Push this repository to GitHub or GitLab.
2. Go to your [Render Dashboard](https://dashboard.render.com).
3. Click **New +** -> **Static Site**.
4. Connect your GitHub/GitLab repository.
5. Set:
   - **Name**: destination-point
   - **Build Command**: *(leave empty)*
   - **Publish Directory**: ./ (or leave as root)
6. Click **Create Static Site**.

### Option 2: Via Blueprint
If you connect your repository with Blueprint, Render will automatically detect ender.yaml and configure the static site instantly.
